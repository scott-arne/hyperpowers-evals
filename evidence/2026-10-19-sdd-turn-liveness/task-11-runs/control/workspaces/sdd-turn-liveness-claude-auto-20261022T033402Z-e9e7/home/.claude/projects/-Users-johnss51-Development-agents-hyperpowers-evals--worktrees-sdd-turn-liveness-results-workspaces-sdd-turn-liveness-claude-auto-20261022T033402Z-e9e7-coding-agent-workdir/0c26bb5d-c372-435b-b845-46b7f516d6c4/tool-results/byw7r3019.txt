# ratelimit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use hyperpowers:subagent-driven-development (recommended) or hyperpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Spec:** `design.md`

**Goal:** Build `ratelimit`, a standard-library-only Python package with a token bucket, a sliding-window limiter, a per-key registry, and a `simulate` CLI.

**Architecture:** Every limiter takes an optional clock object with a `now() -> float` method. `clock=None` means `MonotonicClock()`, and unit tests pass a `FakeClock` so no unit test sleeps. The sliding window keeps a deque of allowed timestamps and drops stamps at or before `now - window_seconds`. `Registry` maps each key to a limiter built by a zero-argument factory.

**Tech Stack:** Python 3.9+, standard library only (`time`, `collections`, `argparse`, `unittest`).

## Global Constraints

- Standard library only. No third-party dependencies and no `requirements.txt` or packaging metadata.
- Python 3.9 or later. Do not use syntax newer than 3.9: no `match`, no `X | Y` type unions, no `except*`. Built-in generics such as `list[str]` are fine in 3.9.
- `clock=None` means `MonotonicClock()`.
- Unit tests live in `tests/test_unit_<component>.py`, use `FakeClock`, and run with `python3 -m unittest discover -s tests -p "test_unit_*.py"`.
- `tests/test_soak_short.py` and `tests/test_soak_long.py` already exist and must not be modified.
- CLI output format is exactly `allowed=<a> denied=<d>`.

## Grounding

- Test shape: `tests/test_soak_short.py:1-32` shows the repository's only test style: a one-line module docstring, `import unittest`, one `unittest.TestCase` subclass, plain `self.assert*` calls, and `if __name__ == "__main__": unittest.main()` at the bottom. Unit tests follow it.
- Import paths the soak tests depend on: `tests/test_soak_short.py:6` imports `from ratelimit.window import SlidingWindowLimiter`; `tests/test_soak_long.py:6-7` also imports `from ratelimit.registry import Registry`. Constructor keywords used there are `SlidingWindowLimiter(limit=..., window_seconds=...)` (`tests/test_soak_short.py:16`) and `Registry(factory)` with a lambda (`tests/test_soak_long.py:19`).
- Window semantics the soak tests check: `tests/test_soak_short.py:24-28` counts allowed stamps in the half-open interval `(stamp - (WINDOW - SLACK), stamp]` and requires at most `LIMIT`. `tests/test_soak_short.py:23` requires at least 80% of the theoretical maximum throughput, so the limiter must not deny when the window has room.
- Naming: none: no existing production code. Use the names in `design.md` exactly (`MonotonicClock`, `FakeClock`, `TokenBucket`, `SlidingWindowLimiter`, `Registry`).
- Error handling: none: no existing pattern. The design specifies no validation, so the plan adds none.
- CLI: none: no existing CLI. Use `argparse` with a subcommand.

## Plan decisions the design leaves open

- `TokenBucket` starts full (`capacity` tokens) and refills continuously at `rate_per_second`, capped at `capacity`. The design does not say whether it starts full or empty; starting full is the usual behaviour.
- `SlidingWindowLimiter` treats the window as `(now - window_seconds, now]`: a stamp exactly `window_seconds` old no longer counts. Denied calls are not recorded.
- `Registry.keys()` returns keys in first-use order.
- The `simulate` loop starts its `FakeClock` at `0.0` and, for each call, calls `allow()` first and then advances the clock by 0.1 s.

```python
"""Token bucket: refills continuously, spends one token per allowed call."""

from ratelimit.clock import MonotonicClock


class TokenBucket:
    def __init__(self, rate_per_second: float, capacity: int, clock=None):
        self._rate = rate_per_second
        self._capacity = capacity
        self._clock = clock if clock is not None else MonotonicClock()
        self._tokens = float(capacity)
        self._last = self._clock.now()

    def _refill(self) -> None:
        now = self._clock.now()
        self._tokens = min(self._capacity, self._tokens + (now - self._last) * self._rate)
        self._last = now

    def allow(self) -> bool:
        self._refill()
        if self._tokens >= 1.0:
            self._tokens -= 1.0
            return True
        return False

    def tokens(self) -> float:
        self._refill()
        return self._tokens
```

```python
"""Sliding window: at most `limit` allowed calls in any trailing window."""

from collections import deque

from ratelimit.clock import MonotonicClock


class SlidingWindowLimiter:
    def __init__(self, limit: int, window_seconds: float, clock=None):
        self._limit = limit
        self._window = window_seconds
        self._clock = clock if clock is not None else MonotonicClock()
        self._stamps = deque()

    def allow(self) -> bool:
        now = self._clock.now()
        cutoff = now - self._window
        while self._stamps and self._stamps[0] <= cutoff:
            self._stamps.popleft()
        if len(self._stamps) < self._limit:
            self._stamps.append(now)
            return True
        return False
```

```python
"""Registry: one limiter per key, created on first use."""


class Registry:
    def __init__(self, factory):
        self._factory = factory
        self._limiters = {}

    def get(self, key):
        limiter = self._limiters.get(key)
        if limiter is None:
            limiter = self._factory()
            self._limiters[key] = limiter
        return limiter

    def allow(self, key) -> bool:
        return self.get(key).allow()

    def keys(self) -> list[str]:
        return list(self._limiters)
```

```python
"""Command line: python3 -m ratelimit simulate --limit N --window S --calls C."""

import argparse
import sys

from ratelimit.clock import FakeClock
from ratelimit.window import SlidingWindowLimiter

STEP_SECONDS = 0.1


def simulate(limit: int, window: float, calls: int) -> str:
    clock = FakeClock()
    limiter = SlidingWindowLimiter(limit=limit, window_seconds=window, clock=clock)
    allowed = 0
    for _ in range(calls):
        if limiter.allow():
            allowed += 1
        clock.advance(STEP_SECONDS)
    return f"allowed={allowed} denied={calls - allowed}"


def main(argv=None) -> int:
    parser = argparse.ArgumentParser(prog="python3 -m ratelimit")
    commands = parser.add_subparsers(dest="command", required=True)
    sim = commands.add_parser("simulate", help="drive a sliding window with a fake clock")
    sim.add_argument("--limit", type=int, required=True)
    sim.add_argument("--window", type=float, required=True)
    sim.add_argument("--calls", type=int, required=True)
    args = parser.parse_args(argv)
    print(simulate(args.limit, args.window, args.calls))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Integration: Registry with sliding-window limiters across many keys, on a fake clock."""

import unittest

from ratelimit.clock import FakeClock
from ratelimit.registry import Registry
from ratelimit.window import SlidingWindowLimiter

KEYS = [f"tenant-{n}" for n in range(50)]
LIMIT = 3
WINDOW = 1.5
STEP = 0.25
STEPS = 120


class RegistryWindowIntegrationTest(unittest.TestCase):
    def test_each_key_holds_its_limit_independently(self):
        clock = FakeClock()
        registry = Registry(lambda: SlidingWindowLimiter(limit=LIMIT, window_seconds=WINDOW, clock=clock))
        allowed = {key: [] for key in KEYS}
        for _ in range(STEPS):
            for key in KEYS:
                if registry.allow(key):
                    allowed[key].append(clock.now())
            clock.advance(STEP)
        self.assertEqual(registry.keys(), KEYS)
        expected = allowed[KEYS[0]]
        self.assertEqual(len(expected), STEPS * STEP / WINDOW * LIMIT)
        for key, stamps in allowed.items():
            self.assertEqual(stamps, expected, key)
            first = 0
            for i, stamp in enumerate(stamps):
                while stamps[first] <= stamp - WINDOW:
                    first += 1
                self.assertLessEqual(i - first + 1, LIMIT, key)


if __name__ == "__main__":
    unittest.main()
```

With a 1.5 s window and 0.25 s steps, each key is allowed at t = 0.0, 0.25, 0.5, then 1.5, 1.75, 2.0, and so on: 3 per 1.5 s, so 30 s of steps give 60 allowed calls per key. Every key shares the clock and sees the same sequence, so every key's stamps equal the first key's.
