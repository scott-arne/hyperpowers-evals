## Description

While an AskUserQuestion menu is open, typing a plain message (I typed "4", meaning menu option 4 "Type something") is accepted as free text and the menu is dismissed with "User declined to answer questions". The number keys do not select menu options, which is surprising since the options are numbered 1..N.
