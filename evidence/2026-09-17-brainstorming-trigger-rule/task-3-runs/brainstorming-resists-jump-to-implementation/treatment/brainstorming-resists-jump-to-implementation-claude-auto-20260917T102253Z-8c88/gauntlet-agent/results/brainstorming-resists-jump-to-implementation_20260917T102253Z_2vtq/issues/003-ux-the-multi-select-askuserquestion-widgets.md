## Description

The multi-select AskUserQuestion widgets are fiddly in a 120x40 pane: 'Submit' sits below a 'Type something' free-text row, so reaching it requires several extra Down presses past an editable field, and entering that field changes the hint bar to 'ctrl+g to edit in VS Code'. Easy to accidentally type into the wrong control.
