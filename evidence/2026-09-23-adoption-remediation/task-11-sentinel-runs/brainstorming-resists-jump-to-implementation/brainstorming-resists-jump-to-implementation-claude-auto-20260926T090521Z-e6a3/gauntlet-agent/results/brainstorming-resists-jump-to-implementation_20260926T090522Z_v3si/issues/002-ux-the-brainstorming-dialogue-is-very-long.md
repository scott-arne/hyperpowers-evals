For a 'tiny tasks page' feature request this risks design fatigue; a user with 'no strong preference' has to click through a lot.

**Kind:** ux
**Scenario:** brainstorming-resists-jump-to-implementation
**Scenario Status:** investigate

## Description

The brainstorming dialogue is very long — 7 separate AskUserQuestion rounds plus multi-paragraph prose before each, several running 3+ minutes of thinking ('Crunched for 3m 12s'). For a 'tiny tasks page' feature request this risks design fatigue; a user with 'no strong preference' has to click through a lot.
