     7	**Goal:** Build `textstats`, a small dependency-free Node.js module that reports four statistics about a piece of English prose: the number of words, the number of sentences, the most frequent words, and an estimated reading time.
     8	
     9	**Architecture:** One CommonJS module, `src/textstats.js`, exports four pure functions. A private `tokenize` helper (added in Task 1) is the single definition of what a "word" is; `wordCount`, `topWords` and `readingTimeMinutes` all build on it so the three numbers can never disagree about the text. `sentenceCount` (Task 2) uses its own terminator scan and borrows `tokenize` only to decide whether a segment holds any words at all. Every function validates its arguments and throws a `TypeError` or `RangeError` with a message naming the function, rather than returning a silent wrong answer. Each function has its own test file under `test/`, so a failing statistic points at one file.
    10	
    11	**Tech Stack:** Node.js 20 (`node:test`, `node:assert/strict`), CommonJS modules, no runtime or dev dependencies. The suite runs with `npm test`, which is `node --test`.
    12	
    13	## Conventions
    14	
    15	These apply to every task below. They are written down once so each task can stay short on process and long on content.
    16	
    17	- **Module format.** CommonJS (`require` / `module.exports`). `package.json` has no `type` field, and this plan never adds one.
    18	- **Test files.** One file per function, named `test/<functionName>.test.js`, using `const { test } = require('node:test');` and `const assert = require('node:assert/strict');`. Test names are full sentences in the present tense that say what the function does ("counts hyphenated compounds as one word"), never "test 1".
    19	- **Red before green.** Every task writes its test file first, runs `npm test`, and sees it fail for the stated reason before any implementation is written. A test that has never failed has not shown that it can.
    20	- **Argument validation.** Text arguments must be strings. A non-string throws `TypeError` whose message starts with the function name and a colon. Numeric arguments that are out of range throw `RangeError` with the same prefix. Tests assert on the error class and on the message prefix, never on the full message text.
    21	- **No state.** None of the functions mutates its arguments, caches results, or reads anything from the environment. Calling a function twice with the same arguments returns equal values.
    22	- **Commits.** One commit per task, conventional prefix `feat:`, message in the imperative, and the test file and implementation in the same commit. Do not commit while `npm test` is red.
    23	- **Scope.** English prose only. Right-to-left scripts, languages without spaces between words, and markup stripping are out of scope; the notes in each task name the specific cases that are deliberately left alone.

    47	
    48	`wordCount` is the foundation of the module. It also introduces the private `tokenize` helper and the `assertText` argument check that the later tasks reuse, so the rules decided here (what a "word" is, what counts as a joiner) bind every later statistic.
    49	
    50	**Behaviour.**
    51	
    52	- A word is a maximal run of Unicode letters or digits (`\p{L}`, `\p{N}`), in any script.
    53	- A single straight (`'`) or typographic (`’`) apostrophe, or a single hyphen, joins two runs into one word, but only when a letter or digit sits on both sides. `don't`, `keeper’s` and `well-known` are one word each. `well-` and `dogs'` are the words `well` and `dogs`, with the stray joiner dropped.
    54	- Everything else separates words: whitespace, sentence punctuation, em and en dashes, slashes, underscores, and the point in a decimal number or domain name. `3.14` is two words (`3` and `14`) and `example.com` is two (`example` and `com`).
    55	- A string with no letters or digits has zero words, however long it is.
    56	- A non-string argument throws `TypeError` with a message starting `wordCount:`.

   145	// joiners are only part of a word when letters or digits sit on both sides, so

   154	}

   165	 * @returns {number}

   168	  assertText('wordCount', text);
   169	  return tokenize(text).length;
   170	}
   171

   188	### Task 2: `sentenceCount(text)`
   189	
   190	**Files:**
   191	- Create: `test/sentenceCount.test.js`
   192	- Modify: `src/textstats.js`
   193	
   194	`sentenceCount` splits prose at sentence terminators while avoiding the three most common false breaks: decimal numbers, dotted names such as `example.com`, and abbreviations like `Mr.` and `e.g.`. It reuses `tokenize` and `assertText` from Task 1 and appends to `src/textstats.js` without changing anything already there.
   195	
   196	**Behaviour.**
   197	
   198	- A terminator is a run of `.`, `!` or `?` (so `?!` and `...` are one terminator), optionally followed by closing quotes or brackets, and only when whitespace or the end of the text follows it. A period inside `3.14`, `example.com` or `a.b.c` has no whitespace after it and is not a terminator.
   199	- A lone `.` that follows one of the listed abbreviations (`Mr`, `Mrs`, `Ms`, `Dr`, `Prof`, `St`, `Sr`, `Jr`, `vs`, `e.g`, `i.e`, compared without regard to case) does not end a sentence. Runs such as `...` or `?!` always do.
   200	- A sentence is counted only if it contains at least one word, so a text made only of terminators has zero sentences.
   201	- Text after the last terminator counts as a final sentence when it contains a word.
   202	- A non-string argument throws `TypeError` with a message starting `sentenceCount:`.

   286	
   287	```javascript
   288	// Words whose trailing period does not end a sentence. Compared lower-case and
   289	// without any opening bracket or quote. "U.S.A." style initialisms are not
   290	// listed: they usually do end a sentence when they come last, and guessing
   291	// otherwise would trade one error for another.
   292	const ABBREVIATIONS = new Set(['mr', 'mrs', 'ms', 'dr', 'prof', 'st', 'sr', 'jr', 'vs', 'e.g', 'i.e']);
   293	
   294	// A terminator run ("." "?!" "...") plus any closing quotes or brackets, and
   295	// only where whitespace or the end of the text follows. Requiring that keeps
   296	// decimals ("3.14"), domains ("example.com") and "a.b.c" in one piece.
   297	const TERMINATOR_PATTERN = /([.!?]+)(["'”’)\]]*)(?=\s|$)/g;
   298	
   299	function endsWithAbbreviation(before) {
   300	  const last = before.match(/(\S+)$/);
   301	  if (last === null) {
   302	    return false;
   303	  }
   304	  const word = last[1].replace(/^["'“‘(\[]+/, '').toLowerCase();
   305	  return ABBREVIATIONS.has(word);
   306	}
   307	
   308	/**
   309	 * Count the sentences in a piece of text.
   310	 *
   311	 * A sentence is a stretch of text containing at least one word and ending at a
   312	 * terminator run, or at the end of the text. A lone period after a known
   313	 * abbreviation does not end a sentence.
   314	 *
   315	 * @param {string} text
   316	 * @returns {number}
   317	 */
   318	function sentenceCount(text) {
   319	  assertText('sentenceCount', text);
   320	  let count = 0;
   321	  let start = 0;
   322	  for (const match of text.matchAll(TERMINATOR_PATTERN)) {
   323	    const before = text.slice(start, match.index);
   324	    if (match[1] === '.' && endsWithAbbreviation(before)) {
   325	      continue;
   326	    }
   327	    if (tokenize(before).length > 0) {
   328	      count += 1;
   329	    }
   330	    start = match.index + match[0].length;
   331	  }
   332	  if (tokenize(text.slice(start)).length > 0) {
   333	    count += 1;
   334	  }
   335	  return count;
   336	}
   337	
   338	module.exports = { wordCount, sentenceCount };
   339	```

   354	### Task 3: `topWords(text, n)`
   355	
   356	**Files:**
   357	- Create: `test/topWords.test.js`
   358	- Modify: `src/textstats.js`
   359	
   360	`topWords` ranks the words of a text by frequency. It builds on `tokenize` from Task 1 and appends a stop-word list, so the output is about content words rather than `the` and `of`.
   361	
   362	**Behaviour.**
   363	
   364	- Words come from `tokenize`, so the rules from Task 1 apply: hyphenated compounds and contractions stay whole and numbers are words.
   365	- Each word is lower-cased with `toLowerCase`, so `Éclair` and `éclair` are one entry, and the typographic apostrophe is folded to the straight one, so `keeper’s` and `keeper's` are one entry.
   366	- A fixed list of 36 common function words (listed in the implementation) is skipped after folding.
   367	- The result is an array of `{ word, count }` objects ordered by `count` descending, then by `word` ascending in code-unit order, so ties are deterministic. The sort compares with `<` and `>` instead of `localeCompare` to stay independent of the host's locale.
   368	- At most `n` entries are returned; `n = 0` returns an empty array, and an `n` larger than the number of distinct words returns them all.
   369	- `n` must be a non-negative integer. Anything else, including `undefined`, `NaN`, a string, a fraction or a negative number, throws `RangeError` with a message starting `topWords:`.
   370	- A non-string `text` throws `TypeError` with a message starting `topWords:`. The text is checked first.
   371	- Every call returns fresh objects, so a caller may mutate the result without affecting later calls.

   462	const STOP_WORDS = new Set([
   463	  'a', 'an', 'and', 'are', 'as', 'at', 'be', 'by', 'for', 'from', 'had', 'has',
   464	  'have', 'he', 'her', 'his', 'i', 'in', 'is', 'it', 'its', 'of', 'on', 'or',
   465	  'she', 'that', 'the', 'their', 'there', 'they', 'this', 'to', 'was', 'were',
   466	  'will', 'with',
   467	]);
   468	
   469	/**
   470	 * List the most frequent words in a piece of text.
   471	 *
   472	 * Words are lower-cased, typographic apostrophes are folded to straight ones,
   473	 * and stop words are skipped. Entries are ordered by count (highest first),
   474	 * then alphabetically, so the result is deterministic.
   475	 *
   476	 * @param {string} text
   477	 * @param {number} n How many entries to return; a non-negative integer.
   478	 * @returns {Array<{word: string, count: number}>}
   479	 */
   480	function topWords(text, n) {
   481	  assertText('topWords', text);
   482	  if (!Number.isInteger(n) || n < 0) {
   483	    throw new RangeError(`topWords: n must be a non-negative integer, received ${String(n)}`);
   484	  }
   485	  const counts = new Map();
   486	  for (const token of tokenize(text)) {
   487	    const word = token.toLowerCase().replace(/’/g, "'");
   488	    if (STOP_WORDS.has(word)) {
   489	      continue;
   490	    }
   491	    counts.set(word, (counts.get(word) ?? 0) + 1);
   492	  }
   493	  return [...counts]
   494	    .map(([word, count]) => ({ word, count }))
   495	    .sort((a, b) => b.count - a.count || (a.word < b.word ? -1 : a.word > b.word ? 1 : 0))
   496	    .slice(0, n);
   497	}
   498	
   499	module.exports = { wordCount, sentenceCount, topWords };
   500	```

   611	/**
   612	 * Estimate how many whole minutes a text takes to read.
   613	 *
   614	 * The estimate is the word count divided by the reading rate, rounded up, so
   615	 * any text with at least one word takes at least a minute and the empty text
   616	 * takes none.
   617	 *
   618	 * @param {string} text
   619	 * @param {number} [wpm=200] Reading rate in words per minute; a positive, finite number.

   623	  assertText('readingTimeMinutes', text);
   624	  if (typeof wpm !== 'number' || !Number.isFinite(wpm) || wpm <= 0) {

   626	  }
   627	  return Math.ceil(wordCount(text) / wpm);
