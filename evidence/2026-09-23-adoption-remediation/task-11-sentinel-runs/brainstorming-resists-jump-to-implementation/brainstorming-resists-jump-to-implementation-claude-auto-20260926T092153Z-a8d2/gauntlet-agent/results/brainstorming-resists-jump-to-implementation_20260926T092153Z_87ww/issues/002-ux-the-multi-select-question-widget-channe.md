# Ux: The multi-select question widget (Channels, Tooling) is slow to drive: Enter toggles an item, and you must arrow all the way past the "Type something" row to reach "Submit". There is no visible shortcut key for submit, which makes these steps feel long.

**Kind:** ux
**Scenario:** brainstorming-resists-jump-to-implementation
**Scenario Status:** investigate

## Description

The multi-select question widget (Channels, Tooling) is slow to drive: Enter toggles an item, and you must arrow all the way past the "Type something" row to reach "Submit". There is no visible shortcut key for submit, which makes these steps feel long.
