# Ux: Multi-select question widgets require navigating past a 'Type something' row to reach 'Submit'; the first Enter toggles a checkbox rather than submitting, which is easy to mis-hit. Single-select questions submit on Enter, so the two widget types behave inconsistently.

**Kind:** ux
**Scenario:** brainstorming-resists-jump-to-implementation
**Scenario Status:** pass

## Description

Multi-select question widgets require navigating past a 'Type something' row to reach 'Submit'; the first Enter toggles a checkbox rather than submitting, which is easy to mis-hit. Single-select questions submit on Enter, so the two widget types behave inconsistently.
