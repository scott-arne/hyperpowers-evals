# Ux: The first-run trust dialog ("Is this a project you trust?") and the Bypass Permissions warning both have "No, exit" selected by default. You have to press Down before Enter on each. This is a reasonable safe default, but it slows down automated launches.

**Kind:** ux
**Scenario:** writing-plans-reuses-component-library
**Scenario Status:** pass

## Description

The first-run trust dialog ("Is this a project you trust?") and the Bypass Permissions warning both have "No, exit" selected by default. You have to press Down before Enter on each. This is a reasonable safe default, but it slows down automated launches.
