# Count Implementation Plan

**Spec:** docs/hyperpowers/specs/2026-10-20-count-design.md

**Goal:** `notes.sh list --count` prints the number of notes.

### Task 1: Count flag

**Risk tier:** low (a one-branch shell change with its own test line)

**Files:**
- Modify: `notes.sh`
- Modify: `test.sh`
- Create: `data/sample.txt`

- [ ] **Step 1: Replace `notes.sh`** with this code (the header and usage string name the new flag; a missing notes file counts as zero, the same answer an empty file gives):

```bash
#!/usr/bin/env bash
# notes.sh add TEXT | list [--count] : a tiny notes CLI backed by notes.txt.
set -euo pipefail
FILE="${NOTES_FILE:-notes.txt}"
case "${1:-}" in
  add) shift; printf '%s\n' "$*" >> "$FILE" ;;
  list)
    if [ "${2:-}" = "--count" ]; then
      if [ -f "$FILE" ]; then wc -l < "$FILE" | tr -d ' '; else echo 0; fi
    elif [ -f "$FILE" ]; then
      cat "$FILE"
    fi
    ;;
  *) echo "usage: notes.sh add TEXT | list [--count]" >&2; exit 64 ;;
esac
```

- [ ] **Step 2: Generate the sample data** with `mkdir -p data && seq 1 5000 > data/sample.txt`. The test counts it as a larger input than two notes.

- [ ] **Step 3: Add these assertions to `test.sh`**, directly before the `sleep` line:

```bash
[ "$(bash notes.sh list --count)" = "2" ] || { echo "expected a count of 2" >&2; exit 1; }
[ "$(NOTES_FILE=/nonexistent/none bash notes.sh list --count)" = "0" ] || { echo "expected a count of 0 for a missing file" >&2; exit 1; }
[ "$(NOTES_FILE=data/sample.txt bash notes.sh list --count)" = "5000" ] || { echo "expected a count of 5000 for the sample file" >&2; exit 1; }
```

- [ ] **Step 4: Run `bash test.sh`**, expect `ok`, and commit `notes.sh`, `test.sh` and `data/sample.txt` together as `feat: list --count prints the number of notes`. Do not leave a `notes.txt` in the working tree.
