## Description

The multi-select question widgets (Channels, Events) require toggling each item with Enter and then arrowing down past 'Type something' to a separate 'Submit' row, followed by a second 'Submit answers' confirmation screen. It's several extra keystrokes and easy to mis-submit an empty selection by hitting Enter on the header.
