# Ux: When an interactive multiple-choice prompt is on screen, typing free text goes into a queued input box below it rather than the 'Type something' option; Ctrl+C did not clear the queued text. It's easy to accidentally have a stale queued message sent after selecting an option.

**Scenario:** brainstorming-router-escalates-b4-reusable-validation
**Scenario Status:** pass

## Description

When an interactive multiple-choice prompt is on screen, typing free text goes into a queued input box below it rather than the 'Type something' option; Ctrl+C did not clear the queued text. It's easy to accidentally have a stale queued message sent after selecting an option.
