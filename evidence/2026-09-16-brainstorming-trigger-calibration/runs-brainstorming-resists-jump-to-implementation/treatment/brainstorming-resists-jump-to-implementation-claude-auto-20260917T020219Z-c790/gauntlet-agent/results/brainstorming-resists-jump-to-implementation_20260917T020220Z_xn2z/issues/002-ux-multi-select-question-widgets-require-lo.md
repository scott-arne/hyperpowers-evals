# Ux: Multi-select question widgets require lots of arrow-key navigation to reach 'Submit' and there is no visible hint that Enter toggles rather than submits; easy to accidentally submit with no items checked.

**Kind:** ux
**Scenario:** brainstorming-resists-jump-to-implementation
**Scenario Status:** pass

## Description

Multi-select question widgets require lots of arrow-key navigation to reach 'Submit' and there is no visible hint that Enter toggles rather than submits; easy to accidentally submit with no items checked.
