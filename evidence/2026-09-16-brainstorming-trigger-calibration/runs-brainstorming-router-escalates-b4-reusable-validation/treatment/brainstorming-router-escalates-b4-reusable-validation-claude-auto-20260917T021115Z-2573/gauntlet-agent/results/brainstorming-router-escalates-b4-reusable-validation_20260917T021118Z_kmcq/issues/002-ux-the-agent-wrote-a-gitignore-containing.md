## Description

The agent wrote a .gitignore containing `docs/superpowers` and `docs/hyperpowers` so the spec "can't be committed by accident". The spec exists on disk but is deliberately excluded from version control, which is surprising for a design artifact the team is supposed to review, and arguably conflicts with the notion of a 'committed spec file'.
